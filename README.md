## Features

- **Extensive Manga & Manhwa Catalog**: Access thousands of titles across multiple Indonesian and English providers.
- **Anime Streaming**: Stream your favorite series with fast video playback, episode tracking, and server switching.
- **Offline Reading**: Download full chapters for smooth offline reading on the go.
- **Progress Sync & History**: Keep track of read chapters, watched episodes, and bookmarks.
- **Smart In-App Notifications**: Receive alerts whenever new chapters and episodes release.
- **Ultra-Fluid UI**: Built with React Native & Expo for smooth 60/120Hz gestures and native performance.
